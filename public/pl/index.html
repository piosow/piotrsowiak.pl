Oprogramowanie, które działa. AI, które naprawdę pracuje.

Nazywam się Piotr Sowiak. Od 2015 roku projektuję, buduję i utrzymuję systemy biznesowe, w których reguły są skomplikowane, a błąd kosztuje. Dziś wbudowuję też AI w produkty i procesy tak, żeby oszczędzało godziny pracy, a nie tylko dobrze wyglądało na demo.

Co robię

Wytwarzanie oprogramowania

Systemy biznesowe od początku do końca: model domeny, architektura, implementacja, wdrożenie i utrzymanie. Rozliczenia płacowe, obieg dokumentów, integracje z bankami i KSeF.

  • .NET
  • ASP.NET Core
  • Blazor
  • SQL Server
  • DDD
  • CQRS

Inżynieria AI

Modele językowe podłączone do prawdziwych systemów: przetwarzanie dokumentów, asystenci pracujący na Twoich danych i automatyzacje z kontrolą, dzięki której wiesz, kiedy wynikowi można ufać.

  • Integracje LLM
  • Agenci
  • Automatyzacja
  • Ewaluacja

Własne produkty

Małe narzędzia i gry, które sam projektuję, buduję i wydaję: gry na Androida i do przeglądarki oraz dodatek do Arkuszy Google.

  • TypeScript
  • Capacitor
  • Apps Script

O mnie

Zaczynam od procesu, nie od listy ekranów. Budowałem systemy rozliczania czasu pracy i dodatków płacowych, obieg dokumentów kosztowych z OCR, ścieżki akceptacji faktur z KSeF i zlecenia przelewów przez API banku. W takich obszarach walidacja, ślad audytowy i przypadki brzegowe to sedno pracy.

Prowadziłem małe zespoły developerskie i nadal codziennie piszę kod. Z narzędzi AI korzystam jak z każdego innego: tam, gdzie się opłacają, z testami i code review dookoła.
