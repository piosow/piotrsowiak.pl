Help & support

Something not working? Email kontakt@piotrsowiak.pl. I build SheetRota myself and usually reply within one working day.

It helps to include what you clicked, what you expected and a screenshot of the sidebar. Please don't send real personal data from your schedule; an example row is enough.

Getting started

  1. Install SheetRota from Google Workspace Marketplace.
  2. Open a spreadsheet and choose Extensions → SheetRota → Open.
  3. Select the rows you want, or leave “All rows” on, and click Check rows.
  4. Click Download .ics and import the file into your calendar, or use Add to Google Calendar next to a row.

No schedule yet? Click Insert example schedule: SheetRota adds a sheet with sample rows that you can edit.

Which columns does it need?

Put headers in row 1. Date and Title are required; Start, End, Description, Location and Time zone are optional. SheetRota recognises common English and Polish names, for example Date/Data, Start/Początek, End/Koniec, Title/Shift/Tytuł, Location/Miejsce. If your headers are different, open 2. Columns and options in the sidebar and pick the columns yourself.

Date and time formats

  • Dates: date cells (best), 2026-11-03, 03.11.2026 or 03/11/2026. In spreadsheets set to a US locale, 11/03/2026 means 3 November.
  • Times: time cells, 09:00, 9.30, 9 or 9:30 pm. A date cell that also contains a time works as the start when there's no Start column.
  • No start time → an all-day event.
  • No end time → the default length from the options (60 minutes unless you change it).
  • End earlier than start (e.g. 22:00–06:00) → the event ends the next day. Good for night shifts.

Time zones

By default SheetRota uses the spreadsheet's time zone (File → Settings) and you can change it in the options. To mix time zones, add a Time zone column with names such as Europe/London, Europe/Warsaw or America/New_York (full list). Summer and winter time are handled automatically.

Importing the .ics file

  • Google Calendar: Settings → Import & export → Import, choose the file and the calendar. Tip: first create a separate calendar (e.g. “Rota”) and import into it.
  • Outlook: Calendar → Add calendar → Upload from file.
  • Apple Calendar: File → Import.

The schedule changed. How do I update the calendar?

An imported file is a one-time copy. Calendars don't reliably update events from a second import, so you may get duplicates. The cleanest way: import into a separate calendar, and when the schedule changes, delete that calendar, create it again and import the new file. Automatic updates are what SheetRota Pro is for.

The download doesn't start

Some browsers block downloads from add-on sidebars. Click Open the file link under the download button, or allow downloads for docs.google.com in your browser settings.

What permissions does it ask for?

Only two: access to the spreadsheet you open it in, and permission to show its sidebar. It can't see your other files, your calendar or your email, and nothing from your spreadsheet is sent to me. See the privacy policy.

Limits

One export checks up to 2,000 rows. For longer schedules, select part of the rows and export in several files.

Uninstalling

Google Sheets → Extensions → Add-ons → Manage add-ons → SheetRota → Uninstall. Events you've already imported stay in your calendar.
