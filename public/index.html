About the studio

piotrsowiak.pl was founded by Piotr Sowiak, a .NET and JavaScript developer from Łódź, Poland. Fewer titles, each one finished properly.

The games are built in TypeScript on HTML5 Canvas and shipped to Android with Capacitor, so the browser and Android versions share one codebase.
