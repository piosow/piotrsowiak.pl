Browser and Android

One codebase: play in your browser or install from Google Play.

Who's behind it

I'm Piotr Sowiak, a .NET and JavaScript developer from Łódź, Poland. I make games after hours, on my own.

The games are written in TypeScript on HTML5 Canvas and wrapped for Android with Capacitor, so the browser and Android versions share one codebase.
