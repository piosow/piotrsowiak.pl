# piotrsowiak.pl

Źródło strony Piotra Sowiaka z Łodzi (oprogramowanie, inżynieria AI, własne produkty): [piotrsowiak.pl](https://piotrsowiak.pl)

Statyczny HTML/CSS/JS bez frameworka, bez build stepu i bez backendu, hostowany
na Cloudflare Workers (statyczne pliki). Wersja angielska i polska, lista gier generowana
z `data/games.json`, strony dodatku SheetRota w `public/sheetrota/`.

Dokumentacja techniczna: [`docs/DEPLOY.md`](docs/DEPLOY.md)
