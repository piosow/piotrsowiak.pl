# Tablica publikacji

Prowadzi ją agent `koordynator`. Każdy wiersz to jeden plik w tym katalogu.

**Statusy:** `planowany` (zlecony przez koordynatora, szkicu jeszcze nie ma) → `szkic` → `do-poprawy` → `zatwierdzony` → `zaplanowany` (w Bufferze) → `opublikowany`, albo `odrzucony`.
Tylko Piotr zmienia status na `zatwierdzony`, sam w pliku albo mówiąc w sesji „zatwierdzam …”.

**Tryb publikacji:**
- `ręcznie`: Piotr publikuje sam (Reddit, HN, Wykop, Discord, grupy FB, prasa, X bez Buffera, TikTok, YouTube).
- `auto-po-zatwierdzeniu`: po zatwierdzeniu post trafia do kolejki Buffera i publikuje się sam.
  **Dotyczy tylko platform, które wprost dopuszczają publikację przez API z własnego konta: Bluesky,
  Mastodon, LinkedIn (profil), Threads.**
